# Tyler Cyert's portfolio

[View the live site](https://www.tylercyert.com/)

This is the source for my portfolio. I'm a software and integration engineer building internal products, integrations, and practical AI tools. The site shows how I approach that work and links to projects you can explore.

## On the site

- **Home:** what I build, how I work, and selected projects.
- **About:** my background and approach to shipping dependable software.
- **Poko:** an adaptive learning app with [public code](https://github.com/tylercyert/poko).
- **DotBox:** a live [site](https://dotbox.zip/) and [workspace](https://app.dotbox.zip/) for visually designing AI agent teams.

## Run locally

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

Open <http://localhost:3000>. The site uses Next.js, React, TypeScript, and CSS. The social preview image is generated by the Next.js app.

## Check

npm run lint
